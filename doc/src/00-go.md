# 围棋入门：规则与基本手法

> **开发前置条件。** 在动手改这个项目的核心功能之前，必须先确认自己已经理解本章
> 所讲的围棋。不要求你会下棋、更不要求有段级，但必须能独立回答：什么是气、
> 什么时候提子、为什么自杀手非法、打劫在本项目里如何处理、怎样判断真眼假眼、
> 立/尖/飞/跳/虎以及拆、双关这些形各是什么几何关系、布局中盘官子在争什么、
> 「金角银边草肚皮」和高低搭配在说什么。
>
> 若这些概念还不清楚，请先读完本章（必要时辅以一盘 9 路对局或任何入门教程），
> **不要**在对围棋本身没有基本了解的情况下去改 `domain/`、`engine/`、`ui/board/`、
> `ui/session/`。规则判断、复盘语义、候选点、死子、棋子连线、引擎查询字段，全部建立
> 在这些概念上；规则和棋形没搞清楚就写核心代码，几乎必然产出错误的合法着、错误的终局、
> 或错误的分析展示。
>
> 本章只讲**够写代码的那一层**。本仓库如何实现这些规则，见第 2 章。

## 规则

### 棋盘与落子

围棋在交叉点上下子，不是格子里。本项目支持 9、13、19 路。两人对弈，黑先白后，
轮流在空交叉点放一枚己方棋子，落下后不再移动。也可以虚着（pass）——不放子、把
回合交给对方。

坐标对外用 GTP 惯例：横坐标字母 `A–T` 跳过 `I`，纵坐标从棋盘底部向上从 1 编号。
代码内部是 `(x, y)`，`y = 0` 在棋盘顶部（第 2 章）。

### 气与棋串

一枚棋子正交相邻的空交叉点，叫做它的**气**。只数上下左右，斜向不算。

```
· · · ·
· ● · ·     ● 有四气
· · · ·
```

同色、正交相连的棋子合成一串，共享气。斜向相邻不算连——那是下一节的「尖」。

```
· · · ·
· ● ● ·     两子一串，气在串的四周空点上
· · · ·
```

### 提子

一串棋的气被全部堵住时，整串从盘上拿走，称为**提子**。提掉的是对方的棋。

```
· ○ ·
○ ● ○
· ▲ ·     ▲ 白落下，黑子气尽，被提掉
```

提子是规则的核心副作用：落子合法与否、盘面哈希、贴目之外的提子计数，全都跟着它走。
客户端在 `Rules.tryPlay` 里先提掉对方没气的串，再检查自己这串还有没有气。

### 自杀

若落子之后己方这串没有气，且这一手也没有提掉任何对方的棋，就是**自杀**。
本项目把自杀视为非法着（`IllegalReason.Suicide`），不会落上去再立刻提掉自己。
「提劫时先提后检查自己」这条顺序很重要：能提掉对方、从而给自己留出气的着法是合法的，
只有真正把自己闷死的才是自杀。

### 打劫与同形再现

最简单的劫：双方可以来回提同一枚子。若允许立刻回提，对局会无限循环。

```
· ○ ● ·
○ ▲ ○ ●     若 ▲ 刚提掉一枚黑子，黑不能立刻在提掉的位置回提
● ○ ● ·
```

许多入门教材只禁止「立刻回提」（单劫）。本项目更严：采用 **positional superko**——
整盘历史上出现过的盘面（只看黑白子的分布，不问谁走），一律不许再现。长劫、多劫、
循环打劫都会被 `IllegalReason.Superko` 拦住。实现上是给每个盘面算一个哈希，放进
`Position.history` 里查重。

### 虚着、终局、贴目

连续两次虚着，对局结束（`consecutivePasses >= 2`）。终局之后不能再落子。

胜负按**中国规则**（数子 / 地盘）：己方活棋子数，加上被己方围住的空交叉点，白方再
加上**贴目**（komi，补偿后手）。本项目贴目可选 6.5 / 7.5 / 0，默认 7.5。

有两点开发时必须记住：

1. 客户端**自己不算目、不判死活**。终局只认「两虚着」；谁领先、哪些是死子、哪里是
   谁的势力，全部来自引擎返回的 `scoreLead` 与 `ownership`。
2. 「中国规则」是发给引擎的 `rules: "chinese"`，和客户端本地的合法着判定是两件事。
   改计分口径改查询；改能不能落子改 `Rules`。

### 活棋：两只真眼

被围住的棋要活，通常需要至少两只**真眼**。一只眼会被对方投入填掉；两只真眼则
永远提不干净——对方走进一只眼，另一只还在，走进去的子自己没气。假眼看起来像
眼，但围住它的棋并不是一个整体，对方可以局部打吃，眼就散了。一只真眼加一只
假眼，仍是死棋。

本项目的 UI 不会在本地画「这是眼」；死活体现在引擎的势力图与死子标记上。
但若你改候选点、死子滞回或终局展示，必须能分清真假眼，否则无法判断引擎给出的
`ownership` 是否合理。判断方法见下一节。

## 基本手法：立、尖、飞、跳、虎

这些不是规则，是行棋的基本几何。棋盘上的「连线」装饰（`StoneLinks`）就是按这些
几何画的。读懂它们，才能读懂棋盘渲染、也才能看懂引擎给出的选点在干什么。

图例：`●` 已有己子，`▲` 这一手，`·` 空点，`×` 需要注意的空点。

### 立

紧靠己方一子，沿直线向边线方向再下一子，称为**立**（取「树立」之意）。
常见于二路、一路，把气立到边上，或把对方往边下压。同一几何、沿边或向中腹延伸
叫**长**。教学上立与长有方向差别，几何上都是正交相邻（Δ 1,0）。

```
────── 边
· ▲ ·
· ● ·     ▲ 立（向边）
· · ·
```

本项目里立和长都映射为 `LinkKind.Nobi`。

### 尖

在己子的斜邻一路落子，称为**尖**（也叫小尖）。两子斜向相邻，中间没有被切断的
直线缝，联络很坚固，俗语「小尖无恶手」。攻守、出头、补断都常用。

```
· · · ·
· ● · ·
· · ▲ ·     ▲ 尖（斜邻一路，Δ 1,1）
```

对应 `LinkKind.Kosumi`。

### 飞

从己子走到「日」字形的对角，称为**小飞**（类似中国象棋的马步，Δ 1,2）。
再远一路、走到「目」字形对角，是**大飞**。飞比尖快、比跳斜，常用来守角、
围空、轻灵出头，但也留有被挖断的空隙。

```
· · ▲ ·
· · · ·     ▲ 小飞（日字对角，Δ 1,2）
· ● · ·
```

本项目只把小飞画成连线，对应 `LinkKind.Keima`。大飞不画。

### 跳

在己子同一条直线上隔一路落子，称为**跳**（一间跳，Δ 2,0）。中间那一点必须是空的。
隔两路是大跳。跳比尖快，常用于出头、逃跑、封锁；中间被对方挤进来就会被分断。

```
· ● · ▲ ·     ▲ 跳（直线隔一路）
```

对应 `LinkKind.Tobi`。中间空点记在 `StoneLink.via` 里，拱线朝远离己方重心的一侧倾斜。

### 虎

先有两子尖形，再向对称的另一侧尖一着，三子成品字，称为**虎**。三子围出的那个
空点是**虎口**：对方若把子送进虎口，常常立刻被提，或至少落成愚形。虎用来护断，
比直接粘更有弹性，一块棋能同时照看两个断点。

```
· ● ·
● × ▲         ▲ 虎；× 是虎口
· · ·
```

虎不是两子关系，本项目没有 `LinkKind` 与之对应——棋盘连线只画到两子的立/尖/飞/跳。
但死活、补断、引擎选点里会频繁出现这个形，读分析时认不出来就很难判断「这手在干什么」。

## 真眼与假眼

眼是己方棋围住的空交叉点。看起来像眼的不一定能当眼用——区别只有一条：
**围住这个空点的棋，是不是已经连成一个整体。** 真眼里的空点不是棋串互相联络
所必需的；假眼里的空点一旦被堵住或被打吃，围眼的棋就会断开、被提。

实务上用两个互相印证的办法，角、边、腹的差别只在「眼角」数量不同。

### 办法一：看能不能局部打吃

真眼：对方想吃掉围眼的棋，必须先把整块棋的外气全部收紧，最后才能走进眼里提子。
假眼：对方不必包围整块棋，只要在眼的某个对角（眼角）打吃一枚「靠斜线连着」的子，
你就得自己把眼填上，否则那一枚被提，眼随之消失。

```
真眼（中腹）              假眼（中腹）
● ● ●                    ○ ● ○
● · ●                    ● · ●     白占住眼角，黑只靠斜线连
● ● ·                    · ● ●     白打吃后，黑必须自己填眼
```

### 办法二：数眼角

围成一只单点眼时，斜向的交叉点叫做**眼角**（有的书称肩膀）。对方占了足够多的
眼角，围眼的棋就连不成整体，这只眼就是假的。口诀：

| 位置 | 眼角数量 | 假眼的经验条件 |
| --- | --- | --- |
| 角 | 1 | 那一只眼角被对方占住 |
| 边 | 2 | 两只里至少一只被对方占住 |
| 腹（中腹） | 4 | 四只里至少两只被对方占住 |

角上的真眼与假眼：

```
───                    ───
· ●                    ○ ●         角上只有一只眼角
● ·  真眼               ● ·         眼角被占 → 假眼
```

边上的真眼与假眼：

```
──────────             ──────────
● · ●                  ● · ●
● ● ●  真眼             ● ● ○      一只眼角被占 → 假眼
```

中腹的真眼与假眼（斜向四个交叉点就是四只眼角）：

```
● ● ●                  ○ ● ○
● · ●  真眼             ● · ●     两只（或更多）眼角被占
● ● ·                  · ● ●     → 假眼
```

这是单点眼的快速判别，不是定理：围眼的棋若从别处连成了整体（例如两只眼互相
接应，俗称相思眼），即使眼角看起来不够，仍可能是真眼。最终仍要回到办法一——
对方能不能局部打吃。

### 为什么角比腹容易活

做成两只真眼，角上大约六子就够，边上大约八子，中腹大约十子。角有两条边帮你
围，腹要四面包围。这既是死活的算术，也是后面「金角银边草肚皮」的根源。大眼
（直三、曲三、方四、板六等）在双方正确应对下往往只顶一只眼，不能想当然当成
两眼；本项目不在本地枚举这些形，但读引擎死子标记时要知道「空点多 ≠ 两眼」。

## 愚形与良形

棋形说的是几枚子摆在一起效率高不高：同样的子，气多、联络弹性大、既能围空又
能出头，就是**良形**；挤成一团、气少、被对方一碰就碎，就是**愚形**。引擎的
选点和「质量」标记，很大一部分就是在奖良形、罚愚形。下面这些形要能从盘上认出来。

### 良形

**小飞。** 轻灵、守角、出头都常用，是良形里最活的一种。空隙在「日」字的拐角，
对方可以挖。本项目把小飞画成 `LinkKind.Keima`。

**大飞。** 比小飞再远一路（「目」字对角）。步子更大、围空更快，断点也更大，
对方更容易打入。连线层不画大飞。

**跳（单关）。** 直线隔一路，出头快、不容易被挖断，俗语「凡关无恶手」。向中腹
跳常常叫**关** / **单关**，沿边或在接触战里叫跳，几何一样，都是 `LinkKind.Tobi`。

**虎。** 护断的标准良形，比粘更有弹性，虎口本身还能吃子。见上一节。

**双关。** 两个单关并排，四子像一条板凳（有的书直接叫「双」）。联络极厚，
谚语「双关似铁壁」，用来补断或正面出头。代价是步调稍缓，子用得比较「重」。

```
● · ●
· · ·     双关（两个并列的单关）
● · ●
```

**拆、拆二。** **拆**是在三线或四线上，从己子沿边间隔着开拆，用来围空和做根据地。
隔一路是拆一，隔二路是**拆二**，隔三路是拆三。拆二是边上最常见的生根距离：
近了效率低，远了对方容易打入。谚语「一子拆二、立二拆三」——棋越厚，可以拆得越远。

```
三线  ● · · ▲     ▲ 拆二（中间隔两路）
```

**跳马步。** 马步就是小飞那一步（中国象棋的马）。有的讲法把向中腹或斜向跳出的
马步称作跳马步，强调的是轻灵地跳、而不是守角。几何与小飞相同（Δ 1,2），
只是用意从「守」变成「走」。看引擎在中盘向外跳的选点，多半是这个形。

这些良形共同的代价是**空隙**：飞会被挖，跳会被挤，拆二会被打入。良形不是「不会
死」，而是「同样的子，气和效率更好」。

### 愚形

典型愚形是**空三角**：三子占住 2×2 的三格，中间空一点。比「弯」少一气，子
挤在一起却围不出眼，也走不动。虎成品字、空三角挤成团，外形接近、效率天差地别。

```
良形·虎              愚形·空三角
· ● ·                ● ●
● × ▲                ● ·     三子一团，气少，没有眼位
```

再往下是**凝形**（许多子挤成一块，重复劳动）、**裂形**（该连的没连上，被对方
一碰就断）。引擎把某手标成大恶手，常见原因就是走成了空三角或把拆二拆得过远
变成裂形。不要在渲染层把「挤在一起」画成厚势——厚的是双关那种有弹性的连，
不是团子。

## 基本行局：布局、中盘、官子

一盘棋习惯上分成三段。引擎的胜率曲线在这三段的含义不一样，改复盘或形势图时
不要用同一把尺子。

**布局（序盘）。** 先占角，再占边，最后才向中腹发展。常见手段是占星位 / 小目、
挂角、守角、拆边。这一段很少直接对杀，争的是实地与外势的分配、以及以后作战
的根据。读开局候选点，优先想「这是占角、拆边还是拆散对方的角」，而不是「能
吃几子」。

**中盘。** 双方接触之后，打入、侵消、攻杀、做活同时出现。一块棋有了根据
（拆二一类的生根）才敢作战；没有根据的孤棋会被对方当攻击的目标。局势预测
（虚子向前走）主要发生在这一段：看的是「这块棋能不能逃、对方能不能封锁」，
不是官子上的一两目。

**官子。** 大块的死活大致确定之后，开始收边界上的目。先手官子（走了对方必须应，
你还保留先手）价值高于后手官子。终局前的胜率 / 目差对这一两目非常敏感；曲线
在官子阶段抖一下，常常只是收官次序，不一定是恶手。客户端把连续两虚着当作终局，
真正的目差仍问引擎。

## 经典思路

这些不是规则，是几百年沉淀下来的默认优先级。引擎在布局和中盘的选点，大体仍
顺着它们；和它们明显相反的一手，要么是有具体计算，要么就是该标质量脸的恶手。

**金角银边草肚皮。** 同样多的子，角最容易围成空（两条边帮你），边次之（一条边），
中腹最难（四边都要自己围）。所以开局的价值顺序是角 → 边 → 腹。中腹不是没有用，
它的价值在于**势**和作战的通路（「入腹争正面」），不是先去围一个方块空。
势力图在中腹大片涂色，读的是影响力，不要理解成已经确定的目。

**高低搭配。** 三路偏低，容易围实地；四路偏高，容易取外势、封锁对方。只走三路
会被对方从上面压扁（「莫压四路，休爬二路」是相关的警告：自己也不要一路爬死），
只走四路则实地漏风。好的阵势是高低错落：一边拆在三路取地，一边在四路出头或
镇住对方。拆二出现在三路或四路，意思完全不同——三路拆二是根据地，四路拆二
是势力范围。

和本项目直接相关的读法：

- 占角、守角、拆边的候选点，优先用「金角银边」去理解；
- 三路 / 四路交替出现的选点，优先用「高低搭配」去理解；
- 中腹的跳、关、镇，多半在争势，而不是在围肚皮上的空。
